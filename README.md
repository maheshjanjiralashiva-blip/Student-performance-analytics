# Student Performance Analytics System

A data analysis pipeline built with Python, Pandas, and NumPy to evaluate student academic records and attendance. Developed for the EWB Python with AI program.

## Project Structure
* `students.csv`: The dataset containing 20 student records, subject marks, and attendance.
* `functions.py`: The core logic module containing reusable Pandas and NumPy calculations.
* `main.py`: The execution script that loads the data, runs the analysis, and prints the formatted terminal report.
* `Project_Documentation.md`: The formal 10-section assessment report detailing the project's implementation and outcomes.

## How to Run
1. Ensure Python, Pandas, and NumPy are installed (`pip install pandas numpy`).
2. Run `python main.py` in your terminal.
3. The system will output class summaries, subject-wise statistics, top performers, and attendance flags.
